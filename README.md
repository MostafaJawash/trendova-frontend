# Trendova Frontend

ابدأ الخلفية من `C:\Users\Cellusys\Desktop\Trendova-` عبر `docker compose up -d`، ثم شغّل `npm install` و`npm run dev`.

يوجه Vite طلبات `/api` و`/media` إلى الخلفية كي لا يتصل المتصفح عبر نطاق مختلف. يغيّر `VITE_BACKEND_URL` في `.env` هدف proxy للتطوير والمعاينة فقط.

الصفحات: المنتجات والتفاصيل والتسجيل/الدخول (عامة)؛ السلة والمفضلة والطلبات والإشعارات والملف الشخصي (للمستخدمين المسجلين)؛ لوحة الإدارة والمنتجات والفئات والمستخدمون والطلبات (للمدير). تعريف دخول المدير الافتراضي موجود في `.env` الخاص بالخلفية، ولا يُنسخ إلى هذا المشروع.

للبناء: `npm run build`. Docker: `docker build -t trendova-ui .`.
